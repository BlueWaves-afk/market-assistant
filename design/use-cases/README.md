# Individual use-case specifications

All use-case specs are indexed in [`../TRACEABILITY.md`](../TRACEABILITY.md). The files use the stable UC IDs and aliases from [`../../docs/USE_CASES.puml`](../../docs/USE_CASES.puml).

Each spec covers purpose, actor, trigger, preconditions, input/output contracts, normal and failure flows, functional requirements, constraints, dependencies, and acceptance criteria. Shared requirements are in [`../REQUIREMENTS.md`](../REQUIREMENTS.md); shared data semantics are in [`../DOMAIN_CONTRACTS.md`](../DOMAIN_CONTRACTS.md).
